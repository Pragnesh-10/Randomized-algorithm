2. What the algorithm is doing

Step 1 · Start
Build 52 unique cards.
Step 2 · Choose
Pick random index j from 0 to i.
Step 3 · Swap
Exchange cards at i and j.
Step 4 · Repeat
Move i left. Stop at i = 1.
Step 5 · Verify
Check every rank-suit pair appears once.

C code at the heart of it

for (int i = 51; i > 0; i--) {
    int j = rand() % (i + 1);
    Card temp = deck[i];
    deck[i] = deck[j];
    deck[j] = temp;
}

For a uniform shuffle, each j must be chosen uniformly. The simple rand() modulo expression is easy to teach but can introduce modulo bias.

4.

“We begin with 52 unique cards. Fisher–Yates starts at the last index. It chooses a random position from the unprocessed part of the deck and swaps those cards. After 51 swaps, the deck is shuffled. We validate that every card appears exactly once, then deal five cards to each of four players. The shuffle runs in O(n) time and uses O(1) extra space.”
